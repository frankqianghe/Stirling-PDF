How to Install Plex PDF

1

Download the installer

Go to the download page, review and accept the EULA and Terms of Service, then click Download Plex PDF for Windows. The installer file (PlexPDF-setup-v1.5.0.msi, 85 MB) will be saved to your Downloads folder.

2

Verify the digital signature (recommended)

Right-click the downloaded .msi file → Properties → Digital Signatures. Confirm the signer is "Wenx Studio LTD.". If the signature is missing or different, do NOT install the file — contact us at support@wenxstudio.com immediately.

3

Run the installer

Double-click PlexPDF-setup-v1.5.0.msi. If Windows Defender SmartScreen shows a warning, click More info → Run anyway (this is expected for software downloaded from the web).

4

Accept the License Agreement

In the installer wizard, read the End-User License Agreement. Select "I accept the terms in the License Agreement" to enable the Next button, then click Next. The installation will not proceed without this acceptance.

5

Choose installation location

The default installation path is C:\Program Files\Plex PDF\. Click Next to accept, or Change to select a different folder.

6

Complete the installation

Click Install and wait for the installation to finish (typically under 1 minute). Click Finish. Plex PDF will launch automatically. You can also find it in the Start Menu or via the desktop shortcut.

💡 Tip: Plex PDF does not install any third-party software, toolbars, browser extensions, or advertising components. The installer only contains Plex PDF and the Windows runtime libraries it requires.

How to Uninstall Plex PDF

You can uninstall Plex PDF at any time. Choose the method that works best for you:

A Via Windows Settings (Recommended)

  1. Press Win + I to open Settings
  2. Go to Apps → Installed Apps
  3. Search for "Plex PDF" in the search box
  4. Click the ⋮ (three dots) next to Plex PDF → select Uninstall
  5. Follow the on-screen prompts to complete removal

B Via Control Panel

  1. Open Control Panel (search for it in the Start Menu)
  2. Go to Programs → Programs and Features
  3. Find Plex PDF in the list
  4. Right-click → Uninstall
  5. Follow the on-screen prompts

C Via Start Menu

  1. Open the Start Menu and search for Plex PDF
  2. Right-click the app icon → Uninstall
  3. Follow the on-screen prompts

What Gets Removed

The uninstaller completely removes Plex PDF from your system:

  • ✓ All Plex PDF application files
  • ✓ Start Menu shortcuts and desktop icon
  • ✓ Application registry entries
  • ✓ Temporary files created by the application
  • ✓ Background services (if any) started by Plex PDF

✅ Your personal PDF files are never modified or deleted during uninstallation. The uninstaller only removes Plex PDF's own files. Your documents remain exactly where you saved them.

Frequently Asked Questions

Does Plex PDF install any other software alongside itself?
No. Plex PDF is a clean install. Our installer contains only the Plex PDF application and standard Microsoft runtime components (e.g., .NET Framework) that Windows requires. We do not bundle any third-party applications, browser extensions, toolbars, advertising components, or any other software.
Is Plex PDF safe to install? Why does Windows SmartScreen show a warning?
Yes, Plex PDF is safe. Our installer is digitally signed with an Extended Validation (EV) Code Signing Certificate issued to Wenx Studio LTD., which verifies our company identity and proves the file has not been tampered with. You can verify this by right-clicking the installer → Properties → Digital Signatures.

If SmartScreen shows a warning, it is because any newly published software may initially display this message. Click More info → Run anyway to proceed. EV code signing provides immediate SmartScreen reputation.
Does Plex PDF read my documents or upload them anywhere?
No. Never. Plex PDF processes all your PDF files entirely on your local device. We do not upload, access, read, or store the content of your documents. All editing, conversion, and OCR operations happen locally on your machine. Your privacy is by design.
How do I update Plex PDF to the latest version?
Plex PDF checks for updates automatically when you launch the application and will notify you when a new version is available. You can also check manually via Help → Check for Updates within the application.

For Lifetime license holders, minor updates are included at no cost. Major version upgrades (e.g., v1.x → v2.x) may require a separate purchase at our discretion. Yearly plan subscribers receive all updates during their active subscription period.
What data does Plex PDF collect?
We collect: (1) license validation information to confirm legitimate use, (2) anonymized usage statistics to understand which features are used, and (3) crash/error reports to fix bugs. We never collect your document content. For full details, see our Privacy Policy.
